# Unsupervised Learning

## 📌 Pengertian
Unsupervised Learning adalah metode dalam Machine Learning yang digunakan untuk menemukan pola atau struktur dari data tanpa label atau target.

Pada metode ini, model akan belajar sendiri dari data untuk:
- Mengelompokkan data
- Menemukan hubungan antar data
- Mengurangi dimensi data
- Menemukan pola tersembunyi

---

# 🎯 Tujuan Unsupervised Learning
Tujuan utama dari Unsupervised Learning adalah:
- Menemukan pola tersembunyi
- Mengelompokkan data yang mirip
- Mempermudah analisis data
- Mengurangi kompleksitas data

---

# 📚 Jenis-Jenis Unsupervised Learning

## 1. Clustering
Clustering digunakan untuk mengelompokkan data berdasarkan kemiripan.

### Contoh Algoritma:
- K-Means
- DBSCAN
- Hierarchical Clustering

### Contoh Penggunaan:
- Segmentasi pelanggan
- Analisis perilaku pengguna
- Pengelompokan dokumen

---

## 2. Dimensionality Reduction
Digunakan untuk mengurangi jumlah fitur pada data.

### Contoh Algoritma:
- PCA (Principal Component Analysis)
- t-SNE

### Fungsi:
- Mempercepat training
- Mengurangi noise
- Mempermudah visualisasi data

---

# ⚙️ Cara Kerja Unsupervised Learning
1. Mengumpulkan data
2. Membersihkan data (preprocessing)
3. Memilih algoritma
4. Melatih model
5. Menganalisis hasil cluster atau pola

---

# 📊 Kelebihan
- Tidak membutuhkan label data
- Dapat menemukan pola tersembunyi
- Cocok untuk data besar
- Membantu eksplorasi data

---

# ❌ Kekurangan
- Hasil sulit diinterpretasikan
- Evaluasi model lebih sulit
- Sensitif terhadap noise
- Membutuhkan preprocessing yang baik

---

---

# 🔍 Perbedaan Supervised dan Unsupervised Learning

| Supervised Learning | Unsupervised Learning |
|---|---|
| Memiliki label | Tidak memiliki label |
| Ada target prediksi | Tidak ada target |
| Digunakan untuk prediksi | Digunakan untuk mencari pola |
| Contoh: klasifikasi | Contoh: clustering |

---

# 📌 Kesimpulan
Unsupervised Learning adalah metode Machine Learning yang digunakan untuk menemukan pola tersembunyi pada data tanpa label. Teknik ini banyak digunakan dalam clustering, segmentasi data, analisis perilaku pengguna, dan berbagai aplikasi AI modern.
